# Error Codes

Les codes ci-dessous sont définis dans
`domain/exception/ServiceProviderErrorCode.java`. Les endpoints indiqués
correspondent aux opérations qui peuvent déclencher chaque erreur.

| Type                        | HTTP | Code métier                | Description                                            | Endpoints concernés                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
|-----------------------------|-----:|----------------------------|--------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ResourceNotFoundException` |  404 | `SERVICE-PROVIDER_404_001` | User Not Found                                         | `POST /service-provider`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `ResourceNotFoundException` |  404 | `SERVICE-PROVIDER_404_002` | Service Provider Not Found                             | `GET /service-provider/{serviceProviderId}`, `PUT /service-provider/{serviceProviderId}/approve`, `PUT /service-provider/{serviceProviderId}/reject`, `GET /service-provider/profile`, `PUT /service-provider/profile`, `POST /service-provider/portfolio`, `PUT /service-provider/portfolio/{portfolioId}`, `DELETE /service-provider/portfolio/{portfolioId}`, `POST /service-provider/services`, `GET /service-provider/{serviceProviderId}/services`, `POST /me/favorites/service-providers/{serviceProviderId}` |
| `ResourceNotFoundException` |  404 | `SERVICE-PROVIDER_404_003` | Service Type Not Found                                 | `POST /service-provider`, `POST /service-provider/services`                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `ConflictException`         |  409 | `SERVICE_PROVIDER-409-001` | This User Is Already Service Provider                  | `POST /service-provider`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `ConflictException`         |  409 | `SERVICE_PROVIDER-409-002` | Service Provider Already Exists With this Phone Number | `POST /service-provider`, `PUT /service-provider/profile`                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `ConflictException`         |  409 | `SERVICE_PROVIDER-409-003` | Service Provider Already Provides Service              | `POST /service-provider/services`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `ConflictException`         |  409 | `SERVICE_PROVIDER-409-004` | Invalid Service Provider Status Transition             | `PUT /service-provider/{serviceProviderId}/approve`, `PUT /service-provider/{serviceProviderId}/reject`, `PUT /service-provider/profile`, `POST /service-provider/portfolio`                                                                                                                                                                                                                                                                                                                                         |
| `BadRequestException`       |  400 | `SERVICE_PROVIDER-400-001` | Invalid Service Provider Pagination Data               | `GET /service-provider`, `GET /service-provider/search`, `GET /me/favorites/service-providers`                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `BadRequestException`       |  400 | `SERVICE_PROVIDER-400-002` | Cannot Favorite Own Profile                            | `POST /me/favorites/service-providers/{serviceProviderId}`                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `BadRequestException`       |  400 | `SERVICE_PROVIDER-400-003` | Invalid Service Provider Phone Number                  | `POST /service-provider`, `PUT /service-provider/profile`                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `BadRequestException`       |  400 | `SERVICE_PROVIDER-400-004` | Invalid Service Provider Year of Experience            | `POST /service-provider`, `POST /service-provider/services`                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
