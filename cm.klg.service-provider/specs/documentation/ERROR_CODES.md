# Error Codes

Cette liste reflète les codes définis dans
[
`ServiceProviderErrorCode.java`](../../src/main/java/cm/klg/service_provider/domain/exception/ServiceProviderErrorCode.java)
et leur traduction HTTP dans
[
`DefaultDomainToHttpExceptionTranslator.java`](../../src/main/java/cm/klg/service_provider/adapter/rest/inbound/DefaultDomainToHttpExceptionTranslator.java).
Les routes sont celles de [`main.yml`](../openapi/inbound/main.yml).

| Exception métier                                       | HTTP | Code                       | Description                                                                                        | Opérations concernées                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|--------------------------------------------------------|-----:|----------------------------|----------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `UserNotFoundException`                                |  404 | `SERVICE-PROVIDER_404_001` | Utilisateur introuvable                                                                            | `POST /service-provider`                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `ServiceProviderNotFoundException`                     |  404 | `SERVICE-PROVIDER_404_002` | Prestataire introuvable                                                                            | `GET /service-provider/{serviceProviderId}`, `GET /service-provider/{serviceProviderId}/verification`, `GET /me/service-provider`, `GET /me/service-provider/identity`, `PUT /me/service-provider/application`, `PUT /me/service-provider/profile`, décisions admin de candidature/photo, détail admin photo, portfolio du prestataire courant et portfolio public, ajout/suppression de service, services publics, ajout aux favoris                                                            |
| `ServiceTypeNotFoundException`                         |  404 | `SERVICE-PROVIDER_404_003` | Type de service du catalogue introuvable                                                           | `POST /service-provider`, `POST /service-provider/services`                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `UserServiceNotFoundException`                         |  404 | `SERVICE-PROVIDER_404_004` | Le prestataire ne propose pas ce type de service                                                   | `DELETE /service-provider/services/{serviceTypeId}`                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `PortfolioItemNotFoundException`                       |  404 | `SERVICE-PROVIDER_404_005` | Élément de portfolio introuvable pour ce prestataire                                               | `PUT /service-provider/portfolio/{portfolioId}`, `DELETE /service-provider/portfolio/{portfolioId}`                                                                                                                                                                                                                                                                                                                                                                                              |
| `ServiceProviderAlreadyExistsException`                |  409 | `SERVICE_PROVIDER-409-001` | Cet utilisateur est déjà prestataire                                                               | `POST /service-provider`                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `ServiceProviderWithPhoneNumberAlreadyExistsException` |  409 | `SERVICE_PROVIDER-409-002` | Le numéro est déjà utilisé par un autre prestataire                                                | `POST /service-provider`, `PUT /me/service-provider/application`, `PUT /me/service-provider/profile`                                                                                                                                                                                                                                                                                                                                                                                             |
| `ServiceProviderAlreadyProvidesServiceException`       |  409 | `SERVICE_PROVIDER-409-003` | Le prestataire propose déjà ce type de service                                                     | `POST /service-provider/services`                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `InvalidServiceProviderStatusException`                |  409 | `SERVICE_PROVIDER-409-004` | L'opération n'est pas permise dans l'état actuel                                                   | `GET /me/service-provider/identity` (vérification non rejetée), `PUT /service-provider/{serviceProviderId}/approve`, `PUT /service-provider/{serviceProviderId}/reject`, `PUT /me/service-provider/application`, `PUT /me/service-provider/profile`, `GET /service-provider/{serviceProviderId}/profile-image-review`, décisions admin de photo, `POST /service-provider/portfolio`, `PUT/DELETE /service-provider/portfolio/{portfolioId}`, `DELETE /service-provider/services/{serviceTypeId}` |
| `InvalidServiceProviderPaginationDataException`        |  400 | `SERVICE_PROVIDER-400-001` | Paramètres de pagination invalides                                                                 | `GET /service-provider`, `GET /service-provider/search`, `GET /me/favorites/service-providers`, `GET /service-provider/profile-image-reviews`                                                                                                                                                                                                                                                                                                                                                    |
| `CannotFavoriteOwnProfileException`                    |  400 | `SERVICE_PROVIDER-400-002` | Un utilisateur ne peut pas mettre son propre profil en favori                                      | `POST /me/favorites/service-providers/{serviceProviderId}`                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `InvalidServiceProviderPhoneNumberException`           |  400 | `SERVICE_PROVIDER-400-003` | Numéro de téléphone invalide                                                                       | `POST /service-provider`, `PUT /me/service-provider/application`, `PUT /me/service-provider/profile`                                                                                                                                                                                                                                                                                                                                                                                             |
| `InvalidServiceProviderYearOfExperienceException`      |  400 | `SERVICE_PROVIDER-400-004` | Années d'expérience invalides                                                                      | `POST /service-provider`, `POST /service-provider/services`                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `MissingIdentityDocumentsException`                    |  400 | `SERVICE_PROVIDER-400-005` | Les documents d'identité sont requis pour resoumettre une candidature rejetée                      | `PUT /me/service-provider/application`                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `UserPhoneNumberAlreadyExistsException`                |  409 | `SERVICE_PROVIDER-409-005` | Le numéro de contact du prestataire est déjà utilisé comme téléphone d'un autre compte utilisateur | `POST /service-provider`, `PUT /me/service-provider/application`, `PUT /me/service-provider/profile`                                                                                                                                                                                                                                                                                                                                                                                             |

Les opérations de mise à jour et de suppression du portfolio renvoient `PortfolioItemNotFoundException`
(`SERVICE-PROVIDER_404_005`) lorsque l'élément n'appartient pas au prestataire chargé.
